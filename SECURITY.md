# 安全问题报告 · Security

请通过 GitHub 的 **Private vulnerability reporting** 私下报告安全问题。进入仓库的 **Security → Report a vulnerability**。不要把安全问题、真实收藏、凭证或可访问的私密链接提交到公开 Issue。[私密报告入口](https://github.com/isook527/want-to-go-trip-planner/security/advisories/new)

请提供受影响版本、使用合成数据的复现步骤、观察到的影响和可行的缓解方式。

Report security vulnerabilities through GitHub Private vulnerability reporting. Include the affected version, a reproduction with synthetic data, the impact and any mitigation. Keep private material out of public issues.
