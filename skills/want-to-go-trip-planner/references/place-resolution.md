# 地点身份核验

## 证据输入

至少提供：

- `name`、`originalText` 或 `ocrText` 之一；
- `city`、`destination` 或位置提示之一。

可选信号包括多语言别名、分店、商场、区域、楼层、地标、地址片段和分享坐标。原截图不上传。

## 专用提取链路

`scripts/extract_evidence.py` 负责把输入转换成统一证据：

- macOS 截图：优先使用本机 Vision OCR；
- 其他环境截图：使用已安装的 Tesseract；
- 公开链接：只读取公开 HTML、Open Graph 和 JSON-LD，不使用浏览器 Cookie；
- 登录墙、验证码、非公开页面或两种 OCR 都不可用：失败关闭并要求用户补充文字。

提取器同时标记预约、排队、闭店、营业时间和天气敏感关键词，但关键词只是线索，不能直接证明当前状态。原链接和截图名只写入本地 `sourceRefs`。

## 候选评分

评分由以下独立信号组成：

- 店名和别名：42%
- 城市：16%
- 分店、商场、区域或地标：20%
- 地址提示：10%
- 与位置提示距离：8%
- 地图营业状态：4%

分数只表示证据一致性，不表示事实已确认。以下任一情况必须由用户选择：

- 最高分低于0.90；
- 第一、二名差距小于0.10；
- 候选中存在同名或相似分店；
- 地图报告永久关闭；
- 来源城市与候选城市冲突。

## 地点身份记录

用户确认后保留：

- 正式店名和历史别名；
- 分店、地址、坐标和坐标系；
- 各地图供应商 POI ID；
- 证据指纹，不保存服务端原始链接；
- 用户确认时间和最近地图核验时间。

再次遇到相同证据指纹时，可以优先显示已确认地点，但在出行前仍重新核验搬迁、改名和闭店状态。
