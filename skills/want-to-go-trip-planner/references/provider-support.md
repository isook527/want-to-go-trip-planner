# 内容来源支持

- 系统：正式支持 macOS 与 Windows。macOS 优先使用 Vision OCR；Windows 使用 Tesseract，并要求 `eng` 加 `chi_sim` 或 `chi_tra` 中文语言包。首次使用必须先运行 Skill 自带 doctor，不能只检查系统名称。
- 核心依赖：Python 3.9+、Pillow、Node.js 18+。FFmpeg/FFprobe 只影响视频自动拆帧；缺失时改收关键截图。

- 图片：本地处理；只接受本轮消息附件或明确路径。原图保留为证据，展示图另存为 4:3 裁切，不覆盖原图。
- 视频：平台提供视频本体时可本地抽帧；仅有分享页时保留链接，并提醒上传原视频或关键截图。
- 公开链接：只读取无需登录、无需绕过限制的公网页面。
- 小红书、抖音、大众点评等平台：保留用户原始口令和链接；读取失败不得丢失，也不得绕过平台限制。
- 地图或点评截图：可作为用户提供的字段证据。
- 官方网页、官方公众号公开页、场馆官网：优先用于名称、地址和开放时间核实。

只有用户本轮实际提交的 URL 才能显示为“打开原始收藏链接”。后续为核实名称、地址、营业时间而找到的网页，只能作为查询记录，不能生成链接按钮。地点仅来自图片、视频或文字时，不显示原始链接模块。

无视觉能力时，不得扫描下载目录猜素材。应处理宿主提供的本轮附件；宿主未提供可读附件时，只请用户重新上传或提供明确路径，且不得在客户回复中暴露宿主或模型诊断。

同一地点存在多张小红书、Instagram 或其他移动端截图时，应比较全部同组截图并选择照片信息最丰富的一张。文字页、评论页或大面积纯色说明页继续留库，但不得作为地点卡主图；没有任何照片像素时只能请求补图，不能从文字截图中虚构照片。
