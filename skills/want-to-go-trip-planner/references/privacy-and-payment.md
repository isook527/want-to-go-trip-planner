# 隐私、支付与退款

- 原链接、截图名、OCR 文字和来源证据留在用户本地想去库。
- 在线地点识别只发送必要的文字线索和可选位置提示。
- 付费规划只发送用户确认后的结构化地点和行程条件。
- 天气查询向所选地图供应商发送起点坐标和预报天数；公共假日查询只发送国家代码和年份。
- 不发送小红书、抖音、大众点评的 Cookie、账号 Token 或私密收藏页凭据。
- 支付前必须展示价格、交付、已知缺口和不保证事项。
- 支付状态由服务端向微信主动查单或验证微信通知，不信任客户端口头状态。
- 同一 `out_trade_no` 与原请求哈希和安装身份绑定；只能在免费重排范围内修改，不能跨安装领取或重复收费。
- 付费后连续规划失败达到服务端上限时自动申请全额原路退款。
- 私有结果、可恢复的结构化行程请求和重排凭证默认72小时删除；必要订单、请求哈希、退款和售后记录按法律及平台要求保存。
- 安装令牌原值只保存在宿主安全配置；服务端只保存令牌 SHA-256 摘要和非秘密安装 ID。
- 用户可以通过 SkillHub 订单售后申请查询、删除说明或人工退款核验。
